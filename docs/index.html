DeskHatch

Lotus SmartCenter, reborn.

A thin launcher bar at the very top of your screen — click a button, a drawer slides down.
画面最上部に常駐する万能ランチャー。懐かしの SmartCenter を現代に。

⬇ Download (Win / macOS) ★ Star on GitHub
winget install Theta.Deskhatch

What it does

🎯

Slam to the top

The bar hugs the screen's top edge — hit it without aiming. Auto-hide or always-on, with optional space reservation.

🗄️

One-click drawers

Each button slides a drawer down beneath it. Pin to lay several side by side; drag to reorder or merge into tabs.

🔑

Sign in once

Gmail, Calendar, Keep, Tasks, Drive, Maps, Gemini, LINE WORKS… one Google login covers them all.

🗂️

Files & Clip

Explorer-style browser, pinned folders, an Apps shortcut, and a 📎 Clip to stash files / URLs / text.

🧰

Built-in tools

Editor, calculator, timer, stopwatch, clipboard history, bookmarks and a quick web search.

⚙️

Polished

Auto-update on Windows, English / 日本語 UI, themes, multi-monitor, tray Restart / Quit.

Get started

Windows: winget install Theta.Deskhatch — or download the installer (auto-updates) / portable build from the latest release.

macOS: download the universal .dmg from the latest release; on first launch right-click → Open (unsigned build).

Free & open source (MIT). Inspired by Lotus SmartCenter.
